# spud-survival

A small, dependency-free 2D browser survival game inspired by open-world survival games.

## Run

Open `index.html` in a browser, or serve this folder with any static file server.

## Play

Choose **Play**, join **Survival #1**, and explore the procedurally styled island.
Move with **W A S D** or the arrow keys, gather nearby trees and rocks with **E**,
and select inventory slots with **1–5**. The map includes temperate, arid, and
arctic regions, roads, a river, coastal landmarks, quarries, safe zones, and
larger monuments.
